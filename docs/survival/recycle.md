回收系统让你**把用不上的物品一键卖给服务器**，是新手前期赚钱最稳定的途径之一。

## 怎么用？

1. 打开回收界面：主菜单 → 回收，或输入指令打开。
2. 界面里会列出服务器当前**回收的物品**和**单价**。
3. 点击要回收的物品，选择数量，确认出售，金币立即到账。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开回收界面 | `/recycle` 或 `/shop`（以游戏内为准） |
| 查看回收列表 | 界面内浏览 |
| 快速回收背包物品 | 在界面内选择「回收背包」类按钮（如可用） |

## 回收哪些东西最划算？

- **矿物与金属**：铁、金、钻石、远古残骸等，前期挖矿收益大头。
- **怪物掉落物**：腐肉、火药、末影珍珠、凋灵骷髅头等。
- **农业产物**：小麦、胡萝卜、西瓜、可可豆等。
- **打怪副产品**：经验瓶、附魔相关材料。

::: tip 提示
回收价格每天可能有波动（"每日回收"），**价格高的日子多卖点**，价格低就留一留，做做差价。
:::

## 注意事项

- 回收是**直接卖给服务器**，不会产生玩家间的交易纠纷，适合快速变现。
- 与玩家交易（箱子商店/全球市场）通常价格更好，稀有物品建议挂市场卖。
- 回收前确认数量，误卖的东西可能无法找回。
