# 随机传送（BetterRTP）

不知道去哪发展？一条指令把你**随机传送到野外任意地点**，开局必备。

## 常用指令

| 功能 | 指令 |
|---|---|
| 随机传送 | `/rtp` |
| 指定世界传送 | `/rtp 世界名`（如 `/rtp world`） |
| 传送到指定生物群系 | `/rtpbiome 群系名`（如 `/rtpbiome desert`） |
| 团队一起传送 | `/rtpteam`（组队状态下） |
| 传送后返回 | 部分版本支持 `/rtp back` 返回原地 |

## 使用技巧

- **开局第一件事**：`/rtp` 去野外找矿脉，别在主城人堆里挤。
- **寻找特定资源**：钻石找深板岩/山地群系，珊瑚找暖水海洋，用 `/rtpbiome` 精准定位。
- **和朋友一起**：组队后用 `/rtpteam` 可以一起传送，避免传散。
- **资源世界**：采集资源建议去资源世界，那里会定期重置，不怕挖空。

## 注意事项

- 随机传送有**冷却时间**（如有），连点会被限制。
- 传送落点可能在悬崖、岩浆、水面上，**落地先看周围**，必要时带好落地水。
- 某些安全区（主城等）内无法使用随机传送。
- 传送前确认背包没有贵重物品——传送过程如果遇到危险，损失自负哦。
