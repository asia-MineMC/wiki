---
title: 领地系统
description: 圈地建房、权限管理，安心生存的第一步
---

领地系统让你在服务器里**圈一块属于自己的地盘**，防止别人破坏和偷东西。想安心生存，圈地是第一步。

## 快速圈地（三步）

1. **选点**：手持任意物品，左键点一块方块的顶面选择 **第一个点**，右键点另一块方块的顶面选择 **第二个点**（两点形成一个长方体区域）。
2. **创建**：输入 `/res create 领地名字`，系统会扣费并创建领地。
3. **完成**：输入 `/res info` 查看领地信息，或 `/res set build true` 允许别人帮你建造。

::: tip 免费领地
本服有**免费领地**机制（FreeResidence），符合条件的玩家可以免费获得领地，具体条件和数量请在主菜单或游戏内查看。
:::

## 常用指令

### 圈地与选区

| 功能 | 指令 |
|---|---|
| 开始选点 | `/res select`（然后左右键选两个角） |
| 创建领地 | `/res create 名字` |
| 自动圈身边区域 | `/res auto`（自动创建合适大小） |
| 查看当前区域信息 | `/res info` |
| 取消选区 | `/res select reset` |

### 管理与传送

| 功能 | 指令 |
|---|---|
| 传送回领地 | `/res tp 领地名字` |
| 领地名列表 | `/res list` 或 `/res list 玩家名` |
| 重命名领地 | `/res rename 旧名字 新名字` |
| 删除领地 | `/res remove 领地名字`（谨慎！不可恢复） |
| 给领地起别名 | `/res alias 领地名字 别名` |
| 查看领地主人 | `/res seen 玩家名` |

### 权限设置（核心玩法）

用 `/res set 权限 值` 设置整个领地权限，或 `/res pset 玩家名 权限 值` 单独给某个玩家设置权限。

**常用权限：**

| 权限 | 作用 | 建议 |
|---|---|---|
| `build` | 是否可以建造/破坏 | 朋友设 true |
| `use` | 是否可以开箱子、用门、按钮 | 朋友设 true |
| `container` | 是否可以打开容器 | 小心！别随便开 |
| `pvp` | 是否允许玩家间战斗 | 家里建议 false |
| `tnt` / `explosion` | 是否允许爆炸破坏 | 建议 false |
| `fire` | 是否允许火焰蔓延 | 建议 false |
| `creeper` | 苦力怕是否破坏地形 | 建议 false |
| `mob-spawn` | 是否生成怪物 | 家附近可设 false |
| `move` | 是否允许玩家进入 | 私密领地设 false |

**示例：**
- 允许朋友建造：`/res pset 小明 build true`
- 家里禁止爆炸：`/res set explosion false`
- 给领地加成员（简化版）：`/res pset 小明 container true use true`

### 其他玩法

- **出售领地**：`/res market sell 领地名字 价格`，其他玩家可 `/res market buy 领地名字` 购买。
- **出租领地**：`/res lease` 相关指令或服务器 GUI 操作，可按时间出租给玩家。
- **GUI 界面**：站在领地内输入 `/res gui` 用图形界面管理（如果有该功能）。

## 注意事项

- 领地的**最大范围**、**数量上限**与玩家权限/身份有关。
- 超出范围的建造不算违规，但会被视为"蹭边"，建议留出安全距离。
- 用 `/resadmin` 前缀的是管理员专属指令，普通玩家无法使用。
- 圈地需要**金币**，记得先攒钱。
