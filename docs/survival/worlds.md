服务器有多个世界，各有分工。通过主菜单的**传送菜单**或指令快速切换。

## 世界一览

| 世界 | 类型 | 特点 |
|---|---|---|
| 主城 lobby | 大厅 | 出生点、安全区，社交/交易/活动场所，**不可破坏、不可 PVP** |
| 主世界 world | 生存 | 常规生存世界，建筑、定居、发展 |
| 资源世界 | 资源 | **定期重置**，专门用来挖矿采集，不怕挖空 |
| 地狱 world_nether | 下界 | 常规地狱，烈焰人、凋灵骷髅、石英资源 |
| 末地 world_the_end | 末地 | 常规末地，末影龙、鞘翅、末地城 |
| pvp 世界 | 对战 | 玩家对战区域，部分[定时 BOSS](/rpg/mobs)在此刷新 |

## 常用指令

| 功能 | 指令 |
|---|---|
| 查看世界列表 | `/mv list` |
| 传送到世界 | `/mv tp 世界名` |
| 回主城 | 主菜单传送，或 `/spawn`（如可用） |

::: tip 推荐
- **挖矿采集** → 去资源世界（定期重置，随便挖）
- **建家定居** → 主世界
- **日常交易** → 主城
:::

## 各世界规则提醒

- **主城**：禁止破坏、禁止 PVP、禁止刷物品，违者警告/处罚。
- **资源世界**：会定期重置，**别在资源世界建家**，重置后一切消失。
- **pvp 世界**：进入即默认同意 PVP，**死亡掉落物可能无法找回**，贵重物品别带进去。
- 跨世界传送可能收费（如有设置），留意扣费提示。

## 世界刷新与活动

资源世界会按服务器设定**定期重置**，重置前管理员通常会在公告频道提醒，记得及时转移物资。
