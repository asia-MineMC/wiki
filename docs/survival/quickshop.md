---
title: 箱子商店
description: 摆摊开店、收购出售，最方便的玩家交易方式
---

箱子商店是最方便的摆摊方式：**把箱子放在地上，挂个价格标签，其他玩家点一下就能买**。

## 开店：出售物品

1. 放一个**箱子**（普通箱子即可）。
2. 手持你要卖的物品，**左键点击箱子** —— 会出现一个价格标签界面。
3. 输入价格（例如 `100`），按回车确认。
4. 把要卖的物品**放入箱子**，商店就开张了！

其他玩家左键点击商店招牌，即可看到商品并购买；购买后金币自动到账，物品自动进入箱子。

## 开店：收购物品

1. 手持物品，**右键点击箱子**（或使用指令创建收购商店）。
2. 设置收购价格，把用于收购的金币放入箱子。
3. 其他玩家左键点击，即可把物品卖给你，金币自动扣除。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开商店帮助 | `/qs` |
| 查看附近商店 | `/qs find` |
| 查看自己的商店列表 | `/qs shop` |
| 查看商店信息 | 左键点击商店招牌 |
| 删除商店 | 破坏箱子（同时按住潜行 Shift + 破坏） |
| 修改价格 | 重新左键/右键点击箱子设置 |
| 查看商店收入 | 站在箱子前 `/qs info` |
| 设为无限库存 | `/qs unlimited`（有权限时） |

## 进阶技巧

- **隐藏商店名**：开店时使用 `/qs createnonshop`（如可用）可以不显示商店信息，防止被盯上。
- **改名商店**：店名可以设置成自己的商店名称，方便辨认。
- **补货提醒**：箱子里的货卖完会自动提示"商店缺货"。
- **防止熊孩子**：箱子商店自带保护，别人无法直接偷箱子里的物品，只能通过购买交易。

## 注意事项

- 商店价格一旦设置，别人点一下就会交易，**务必核对价格**再确认。
- 收购商店要保证箱子里有足够金币支付。
- 商店数量可能有限制（与权限有关）。
