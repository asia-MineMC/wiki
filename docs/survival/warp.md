# 玩家地标（PlayerWarp）

玩家地标让每个玩家可以**创建自己的公共传送点**：比如你的商店、交易所、活动场地，都可以设成地标让全服玩家一键传送过来。

## 快速创建地标

1. 站在想要设立传送点的位置。
2. 输入 `/pwarp create 地标名字`。
3. 设置地标图标（可后续调整），创建完成！

其他玩家输入 `/pwarp` 打开地标列表，就能看到全服的地标并传送。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开地标列表 | `/pwarp` |
| 创建地标 | `/pwarp create 名字` |
| 传送至地标 | `/pwarp tp 名字` 或点列表传送 |
| 删除地标 | `/pwarp remove 名字` |
| 修改地标图标 | `/pwarp icon 名字` |
| 查看地标详细信息 | `/pwarp info 名字` |
| 查看自己的地标 | `/pwarp list` |
| 修改地标名称 | `/pwarp rename 旧名 新名` |
| 修改地标描述 | `/pwarp description 名字 描述` |

## 地标数量与限制

- 每个玩家可创建的地标数量**有限制**（与玩家权限/身份有关），用完后需要删除旧的才能建新的。
- 地标名字建议**简短好记**，方便别人搜索。
- 地标位置会显示坐标和创建者信息。

## 使用技巧

- **商店宣传**：把商店位置设成地标，名字就叫"XX商店"，等于免费广告。
- **公共设施**：交易所、钓鱼场、刷怪塔等公共设施都能设地标。
- **别乱建**：无意义、捣乱性质的地标会被管理员删除并处罚。

::: warning 注意
地标创建后全服可见，注意隐私——**私人家园不建议公开建地标**，想去朋友家直接用 `/tpa` 类指令或好友传送。
:::
