全球市场是**全服范围的拍卖行**：把东西挂上去，全服玩家都能看到并购买，不用守着摊位。适合出售稀有物品、批量物资，也适合淘便宜货。

## 快速上架（三步）

1. 输入 `/ah` 打开全球市场界面（或从主菜单进入）。
2. 点击「**出售**」按钮，把要卖的东西放进出售栏。
3. 设置价格并确认，物品就上架了！

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开市场 | `/ah` |
| 快速出售手中物品 | `/ah sell 价格` |
| 查看我的上架物品 | `/ah my` |
| 搜索物品 | `/ah search 关键词` |
| 查看市场历史 | `/ah history` |
| 撤销上架 | 在「我的上架」里点击物品取回 |

## 购买物品

1. 打开 `/ah` 市场界面。
2. 浏览或搜索想要的物品。
3. 点击物品查看详情，然后**直接购买**（一口价）或参与**竞拍**。

### 一口价 vs 竞拍

- **一口价**：卖家设置固定价格，直接支付即可立即到手。
- **竞拍**：卖家设置起拍价和时限，出价最高者得。你可以在拍卖结束前不断加价。

## 求购订单

服务器还有**求购功能**（PlayerAuctionsBuyOrder）：如果你急需某种物品，可以发布求购订单，出价收购，等卖家接单。

- 从主菜单或 `/ah` 界面进入求购功能。
- 设置你要收购的物品和价格。
- 卖家看到后会接单完成交易。

## 注意事项

- 上架时**注意手续费**（如有），价格别设太低。
- 竞拍成功会**自动从余额扣款**，记得留足金币。
- 交易纠纷可以找管理员查记录（服务器有全功能日志）。
- 求购订单同样要写清楚价格，避免被恶意高价接单。
