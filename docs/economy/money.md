服务器采用**双货币**体系：金币（主货币）+ 点券（特殊货币）。

## 金币（XConomy）

金币是服务器的核心货币，几乎所有交易（商店、拍卖、抽奖、圈地）都使用金币。

### 常用指令

| 功能 | 指令 |
|---|---|
| 查看余额 | `/bal` 或 `/money` |
| 转账给玩家 | `/pay 玩家名 金额` |
| 查看财富排行 | `/baltop` |
| 请求转账 | `/payrequest 玩家名 金额`（对方确认后到账） |
| 查看转账记录 | `/payhistory` |

### 怎么赚钱？

- 挖矿、打怪、种地、钓鱼获得材料 → [每日回收](/survival/recycle) 卖钱
- 开[箱子商店](/survival/quickshop) 或者挂[全球市场](/survival/auctions) 卖东西给玩家
- 做[每日任务](/rpg/quests)、[签到](/rpg/rewards)、参与服务器活动
- 在[挂机池](/rpg/exppond) 挂机攒资源

### 怎么花钱？

- [圈领地](/survival/residence) 需要金币
- [抽奖箱](/rpg/crates) 每次抽取消耗金币
- 玩家商店购买物资
- 主菜单 → 商城 购买特殊商品

## 点券（PlayerPoints）

点券是服务器的**特殊货币**，比金币更珍贵，主要通过签到、活动、任务、抽奖获得，无法通过打怪直接获取。

### 常用指令

| 功能 | 指令 |
|---|---|
| 查看点券 | `/points` |
| 转账点券 | `/paypoints 玩家名 数量` |
| 查看排行 | `/points top` |

### 点券有什么用？

- 主菜单 → 商城：兑换稀有物品、会员礼包
- 部分高级[抽奖箱](/rpg/crates) 可能消耗点券
- 服务器不定期活动的兑换货币

::: tip 小贴士
点券获取途径少、价值高，交易时务必确认清楚再转账，转错了可不好追回哦。
:::
