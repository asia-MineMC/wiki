服务器的聊天系统由 **TrChat** 驱动，支持私聊、频道、颜色和**@ 提醒**，交流更方便。

## 基本聊天

| 功能 | 指令/操作 |
|---|---|
| 公屏聊天 | 直接输入内容 |
| 私聊玩家 | `/msg 玩家名 内容`（或 `/tell`、`/w`） |
| 回复上一条私聊 | `/r 内容` |
| 查看聊天记录 | `/chat log`（如可用） |

## @ 提醒（AtPlayer）

聊天中输入 **@玩家名** 可以提醒对方：

- 被 @ 的玩家会收到**弹窗提示**（"有人@你！"）和提示音。
- 你的名字在聊天中会**高亮显示**。
- 对方在忙/挂机也能注意到你。

**用法示例：**
```
@小明 快来主城开奖！
```

::: tip 提示
@ 功能适合叫朋友、提醒队友，但**别滥用**刷屏，会打扰别人。
:::

## 聊天规范（必读）

- **禁止刷屏**、广告、人身攻击、辱骂。
- 禁止在公屏发布**侮辱性、政治敏感、违规内容**。
- 交易信息请去[市场](/survival/auctions)或商店频道，公屏叫卖适可而止。
- 违反聊天规范会被禁言/警告/封禁（服务器有敏感词检测与封禁系统）。

## 表情包

- 聊天中可以使用服务器自带的**表情包**（主菜单 → 表情包界面），输入对应表情代码即可展示。

## 小贴士

- 用 `/msg` 私聊时注意，`/msg` 和指令前缀不冲突，放心用。
- 想安静地玩，可以暂时关闭/屏蔽聊天（如有对应设置）。
