---

加入公会，和志同道合的玩家一起发展：**公会领地、公会商店、公会技能、公会活动**，一个人玩不了一整片江山。

## 快速加入/创建

| 功能 | 指令 |
|---|---|
| 打开公会界面 | `/guilds` |
| 创建公会 | `/guilds create 公会名`（需要金币） |
| 加入公会 | `/guilds join 公会名` |
| 查看公会列表 | `/guilds list` |
| 查看公会信息 | `/guilds info` |

## 公会核心功能

### 公会资金与进贡

- 公会发展需要**资金**，成员可以进贡金币。
- 主菜单 → **公会进贡**界面，可以一键进贡。
- 公会资金用于升级公会等级、开启功能。

### 公会领地/基地

- 公会拥有**独立的公会领地**（或公会家园）。
- `/guilds home` 传送到公会基地，`/guilds sethome` 设置基地位置（需权限）。

### 公会升级

- 公会升级后解锁：更多成员名额、更强公会效果、公会商店商品等。
- 升级消耗公会资金，需要全体成员一起进贡。

## 常用指令

| 功能 | 指令 |
|---|---|
| 公会聊天 | `/guilds chat 内容` 或切换频道 |
| 传送至公会基地 | `/guilds home` |
| 设置公会基地 | `/guilds sethome` |
| 查看成员 | `/guilds members` 或界面 |
| 踢出成员 | `/guilds kick 玩家名`（管理员） |
| 任命职位 | `/guilds promote 玩家名`（管理员） |
| 解散公会 | `/guilds disband`（会长） |
| 退出公会 | `/guilds leave` |

## 公会职务

| 职务 | 权限 |
|---|---|
| 会长 | 全部权限：管理成员、升级、解散 |
| 管理员 | 踢人、任命、进贡管理 |
| 成员 | 进贡、使用公会功能 |

## 建议

- **人多力量大**：公会升级和活动都需要人手，积极招人。
- **分工明确**：有人负责进贡、有人负责活动、有人负责外交。
- **遵守规则**：公会内互相尊重，恶意捣乱会被踢出。

::: warning 注意
退会/被踢后，公会相关的个人数据（如贡献度）可能清空，退出前想清楚。
:::
