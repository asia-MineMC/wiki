# 好友系统（HyronicFriends）

添加好友，快速联系、快捷传送、共享游戏时光。好友系统是社交的基础功能。

## 快速添加好友

| 功能 | 指令 |
|---|---|
| 打开好友界面 | `/friends` 或 `/f` |
| 添加好友 | `/friends add 玩家名` |
| 接受好友申请 | `/friends accept 玩家名` |
| 拒绝申请 | `/friends deny 玩家名` |
| 查看好友列表 | `/friends list` |
| 删除好友 | `/friends remove 玩家名` |

## 好友功能

### 好友传送
- 部分服务器支持**好友传送**：`/friends tp 好友名` 传送到好友身边（可能需要对方同意或付费，以游戏内为准）。

### 好友消息
- 好友之间可以**私聊**：`/msg 好友名 内容`（配合聊天系统）。

### 在线提醒
- 好友上线/下线会有提示（如有开启），方便组队开黑。

## 常见问题

| 问题 | 说明 |
|---|---|
| 对方不在线能加吗？ | 可以，好友申请会保留，对方上线后处理 |
| 好友数量上限？ | 通常有上限（如 50 人），与身份/权限有关 |
| 好友能进我领地吗？ | 领地的进入/建造权限需要单独设置（[领地教程](/survival/residence)的 pset 功能），加好友不等于授权领地 |

## 小贴士

- 加了好友后，记得在[领地](/survival/residence)里给朋友开放权限，一起建家。
- 好友系统 + [组队系统](/social/team) 搭配使用，冒险体验更佳。
- 清理不活跃的好友，把好友位留给常玩的伙伴。
