# 组队系统（TeamPlugin）

组队系统让你和伙伴**共享战斗收益、快速集合、统一聊天**——打 BOSS、下副本、野外探险必备。一个队伍最多 **6 人**。

## 快速组队

| 功能 | 指令 |
|---|---|
| 创建队伍 | `/team create` |
| 邀请玩家 | `/team invite 玩家名` |
| 接受邀请 | `/team accept` |
| 拒绝邀请 | `/team deny` |
| 退出队伍 | `/team leave` |
| 查看队伍 | `/team list` 或 `/team info` |
| 解散队伍 | `/team disband`（队长） |

## 队伍功能

### 队伍聊天
- 输入 `/team chat 内容`（或切换队伍频道）可以和队员私聊，其他玩家看不到。

### 队伍召唤
- 队长可以**召唤队员**到自己身边：`/team summon 玩家名`（队员同意后传送，召唤有冷却）。
- 适合打 BOSS 集合、探索分散时汇合。

### 队伍共享
- 击杀掉落/经验**共享规则**以服务器设置为准（通常队伍内共享或按伤害分配）。

## 使用场景

- **打 BOSS**：多人围攻[定时 BOSS](/rpg/mobs)，效率与存活率双提升。
- **下矿洞**：一人挖矿一人放哨，防止被偷袭。
- **野外探险**：迷路了直接召唤集合。

## 注意事项

- 队长权限：只有队长可以邀请、召唤、解散，踢人 `/team kick 玩家名`。
- 邀请有**有效期**（默认 60 秒），过期需要重新邀请。
- 召唤有**冷却**（默认 30 秒），别连点。
- 离队后队伍相关状态（共享标记等）自动解除。

::: tip 提示
组队系统偏轻量（临时队伍），长期组织建议加入[公会](/social/guild)。
:::
