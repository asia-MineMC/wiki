# 全球市场与求购

服务器经济有两块：**全球市场**（上架出售）和**求购系统**（发布想买的东西）。

## 全球市场 `/market`

也可用 `/pa`、`/ah`。

| 指令 | 说明 |
| --- | --- |
| `/market` | 打开市场主界面，浏览所有在售商品 |
| `/market sell 价格 [数量]` | 上架手中物品，可设一口价和数量 |
| `/market cancel [id]` | 取消自己的上架，物品进入邮箱 |
| `/market collect` | 收回过期或已取消上架的物品 |
| `/market amount` | 查看上架数量限制与使用情况 |
| `/market search 关键词` | 按物品名称搜索市场 |
| `/market history [玩家]` | 查看交易记录 |
| `/market mailbox` | 打开邮箱领取款项 / 物品 |

**市场特色**

- **邮箱系统**：取消上架或售出后，款项和物品自动进邮箱，不怕背包满。
- **全服广播**：有人上架 / 购买时全服广播。
- **智能分类与搜索**：支持按类别（方块、工具、武器等）筛选，按价格 / 时间排序。
- **无交易税**：成功交易不扣手续费。
- **上架时效**：默认上架 **14 天**（20160 分钟），过期自动进邮箱。
- **上架限制**：默认最多同时上架 **10 件**，可提升。

**使用流程**：手持物品输入 `/market sell 价格` → 别人 `/market` 浏览购买 → 售出款自动进邮箱 → `/market mailbox` 领取。未售出的到期也进邮箱。

## 求购系统 `/wbuy`

| 指令 | 说明 |
| --- | --- |
| `/wbuy 物品名 数量 单价` | 创建求购（支持中/英文物品名） |
| `/wbuy hand 数量 单价` | 用手上物品快速创建求购 |
| `/wbl` | 查看所有求购订单列表 |
| `/wbm` | 打开求购邮箱，领取收购到的物品 |
| `/wbuy cancel 订单ID` | 取消求购，剩余金额退还 |

**求购特色**

- **主动求购**：发布你想要的物品和出价，不用被动等。
- **与市场联动**：市场里若有匹配你求购的物品，可直接一键卖给你。
- **邮箱收货**：收购到的物品进求购邮箱，`/wbm` 领取。
- **金额锁定**：创建求购时总价从账户扣除并锁定，确保卖家收得到钱。
- **自动退款**：取消订单时剩余金额自动退回。
- **数量限制**：默认最多同时 **10 个**求购订单，可提升。

**买家发布求购**：`/wbuy 钻石 5 1000` 表示单价 1000 金币收 5 个钻石，系统扣除并锁定 5×1000=5000 金币；用 `/wbm` 领货、`/wbl` 看状态。

**卖家卖给求购**：`/wbl` 看求购列表 → 找到对应订单 → 左键点击即可出售 → 款项立即到账。

## 小贴士

- 不确定市场价？先 `/market search` 搜同类商品参考定价。
- 急用钱？设一个略低于市场价的一口价更快出手。
- 想收特定物品没人卖？发 `/wbuy` 让卖家来找你。
- 物品名带空格（如 `Iron Sword`）用引号包裹：`/wbuy "Iron Sword" 1 500`。
- 别忘了定时用 `/market mailbox`（市场）和 `/wbm`（求购）清邮箱。
