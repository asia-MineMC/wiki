欢迎来到 MINEMC！这篇指南带你从零开始，5 分钟上手服务器。

## 注册与登录

本服务器是**离线服务器**（正版/离线都可进入），因此首次进入时必须先注册，之后每次进入都要登录。

| 功能 | 指令 |
|---|---|
| 注册 | `/register 密码 密码`（两遍密码相同） |
| 登录 | `/login 密码` |
| 修改密码 | `/changepassword 旧密码 新密码` |
| 退出登录 | `/logout`（换号前先执行） |
| 绑定邮箱 | `/email add 邮箱`（找回密码用，建议绑定） |

::: warning 注意
- 请务必记住密码！忘记密码只能找管理员重置。
- 登录前不能移动，防止别人看到你 ID 后抢先登录。
- 下线前建议 `/logout`，防止被人顶号。
:::

## 主城与主菜单

- 出生点在主城（lobby），主城是安全区，**不能破坏也不能 PVP**。
- 在主城按 **Shift + 右键**（或直接按设置的快捷键）即可打开**服务器主菜单**。
- 主菜单里有：传送、商店、背包商店、宠物商店、公会进贡、会员礼包、指令教学、表情包等入口，几乎覆盖所有功能。

## 世界介绍

服务器有多个世界，通过主菜单的**传送菜单**或指令前往：

| 世界 | 说明 |
|---|---|
| 主城 lobby | 出生点，安全区，社交与交易都在这里 |
| 主世界 world | 常规生存世界 |
| 资源世界 | 采集资源专用，定期重置，随便挖 |
| 地狱 / 末地 | 常规下界与末地 |
| pvp 世界 | 玩家对战区域（部分 BOSS 也在此刷新） |

各世界详细介绍见[世界介绍](/survival/worlds)。

## 货币体系

服务器有**两种货币**：

- **金币**：主要货币，交易、开店、抽奖都用它。查看余额 `/bal`。
- **宝石**：特殊货币，靠签到、活动、任务获得，可购买特殊商品。查看余额 `/points`。

详见[金币与宝石](/economy/money)。

## 生存发展路线建议

1. **开局**：`/rtp` 随机传送到野外，或者去资源世界挖矿攒第一桶金。
2. **赚钱**：挖矿、打怪、做[每日任务](/rpg/quests)、每日[签到](/rpg/rewards)、去[回收](/survival/recycle)卖东西。
3. **安家**：攒够钱后用 [Residence](/survival/residence) 圈一块领地，盖房子、放箱子。
4. **变强**：刷[技能](/rpg/skills)、搞[附魔](/rpg/enchanting)、打[BOSS](/rpg/mobs)拿装备。
5. **社交**：加[公会](/social/guild)、交[好友](/social/friends)、和伙伴[组队](/social/team)。
