# 单挑决斗

想找人切磋、上分冲段位、拿每日奖励，就用单挑系统。

## 怎么开始

- **单挑大厅**：`/dt` 打开图形化大厅，发起挑战、匹配队列、观战、排行榜、我的战绩一键直达。
- **邀请好友**：`/duel 玩家名` 发起单挑，对方点聊天框的 **[接受] / [拒绝]**。
- **随机匹配**：`/queue` 进入队列，自动配对**同装备**的对手。
- **无需自备装备**：进入竞技场自动发放官方装备，**打完自动收回，背包原样返还**。

## 竞技场与装备

- **下界合金场 ×2**：双场并行，排队更快
- **铁套场**：入门体验，节奏更快
- **钻石套场**：经典对决
- **弓箭场**：场上**没有近战武器**，只能远程对射

不同装备局的积分与规则完全一致。

## 积分与段位

每赢一场 **+10 积分**，每输一场 **−10 积分**。

| 段位 | 所需积分 | 升段奖励（一次性） |
| --- | --- | --- |
| 流浪者 | 0 | — |
| 猎手 | 150 | 20 宝石 + 钻石 ×5 |
| 附魔师 | 600 | 50 宝石 + 绿宝石 ×10 |
| 领主 | 1000 | 100 宝石 + 附魔钥匙 ×1 |
| 屠龙者 | 3000 | 200 宝石 + 附魔钥匙 ×2 |

- **屠龙者专属排面**：晋升屠龙者后，每次进服触发**全服专属广播**。
- **查询战绩**：`/adpoints` 看自己的积分与段位，`/adpoints top` 看全服排行榜。

## 每日对战奖励

每天打单挑就有奖励（**每日凌晨 4 点刷新**）：

- **每日胜利奖励**：每天前 **5 场**胜利，每场 **200 金币**。
- **每日首胜**：每天首胜额外 **10 宝石**。

> 每日赢分上限 **300 积分/天**，到上限后当天不再加分，但金币奖励照发。

## 规则

- 禁止丢弃物品、打开箱子、使用传送命令（`/home`、`/warp`、`/tp` 等）。
- 离开竞技场区域视为逃跑，直接判负。
- 比赛中掉线判负。
- 比赛中 `/rank` 可主动认输退出。
- 双方都 `/duel draw` 可协商平局（不结算积分与奖励）。
- **同 IP 对战不计积分、不发奖励**（禁止开小号互刷，违者清零）。

## 防刷机制

- **每日赢分上限**：每天最多 **300 积分**。
- **连败冷却**：连续输 **10 场**后进入 **60 分钟**休息时间，赢一场立即解除。

正常胜负交替的玩家不受影响。

## 观战

- `/duel spectate` 打开竞技场选择，点击观战进行中的比赛。
- 观战为旁观者模式，不影响对决；传送到竞技场外即可退出。
