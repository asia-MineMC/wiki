# 新手入门

欢迎来到 MINEMC。这里只运营一座 **1.21.11 养老生存服**，进服不装整合包、也不用先注册网页账号。

## 怎么进服

1. 准备好 **Java 版 1.21.11** 客户端。
2. 「多人游戏」→「添加服务器」，地址填 **play.minemc.asia**。
3. 进服后按聊天栏提示完成 **注册 / 登录**。
4. 进服后按 **Shift+F** 打开主菜单，挑一个世界落脚。

## 账号命令

首次进入需要先注册，之后每次进服登录一次即可。

| 功能 | 指令 |
| --- | --- |
| 注册 | `/register 密码 密码`（两遍密码相同） |
| 登录 | `/login 密码` |
| 修改密码 | `/changepassword 旧密码 新密码` |
| 退出登录 | `/logout`（换号前先执行） |
| 绑定邮箱 | `/email add 邮箱`（找回密码用，建议绑定） |

::: tip 小提示
- 服务器使用**离线模式 + LimboAuth 代理层认证**，不需要正版账号。
- 密码忘了又没绑邮箱，只能联系管理员重置，建议进服先把邮箱绑上。
:::
