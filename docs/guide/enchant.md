# 自定义附魔

本服在**原版附魔**之外，额外加入了 **ExcellentEnchants** 拓展包，共 **79 种自定义附魔**：**普通附魔 58 种** + **宝物附魔 21 种**。

## 怎么获得

| 途径 | 说明 |
| --- | --- |
| 附魔台 | 58 种普通附魔可直接在附魔台附到对应物品上（宝物附魔不行） |
| 宝箱 / 自然战利品 | 全部 79 种都可能出现在世界各地生成的宝箱里 |
| 钓鱼 | 宝物附魔（尤其「自动鱼线」等钓鱼竿类）的主要来源 |
| 生物装备 | 僵尸、骷髅等身上可能带着 58 种普通附魔 |
| 村民交易 | 可买到已附魔装备；图书管理员暂不出售自定义附魔书 |
| 铁砧 | 用附魔书 + 物品在铁砧上合成、升级 |

## 权重与概率

每个附魔都有隐藏 **权重（1–1024）**，本服实际只用了四档。权重越高越常见：

| 权重档 | 单种占比 | 定位 |
| --- | --- | --- |
| 权重 10 | 约 2.7% | 最常见 |
| 权重 5 | 约 1.35% | 较常见 |
| 权重 2 | 约 0.54% | 较少见 |
| 权重 1 | 约 0.27% | 稀有 |

> 这是「相对权重占比」，不是固定概率。实际概率 = 该附魔权重 ÷ 当前途径下所有可获取附魔的总权重；同一附魔在附魔台、宝箱、钓鱼里的概率都不一样。

## 宝物附魔（21 种）

宝物附魔（各类「诅咒」、自动鱼线、末影弓、隔空取物、夜视仪、再生、弹性等）**无法通过附魔台获得，也不会出现在生物装备上**，只能从 **宝箱战利品、钓鱼、村民交易装备** 获取，通常更强大或更稀有。

## 斩首附魔

给剑或斧附上「斩首」后，击杀生物或玩家有概率直接掉落**对应实体的头颅**，概率随等级提升：**I 级 3%、II 级 5%**（每级 +2%），头颅会按实体类型自动命名。

**可掉落头颅的生物（63 种）**：蜜蜂 鹦鹉 卫道士 猪 海豚 疣猪兽 僵尸村民 蠹虫 鸡 热带鱼 女巫 鱿鱼 蜘蛛 恼鬼 唤魔者 炽足兽 行商羊驼 河豚 猫 北极熊 铁傀儡 鲑鱼 海龟 骷髅马 远古守卫者 僵尸疣猪兽 劫掠兽 绵羊 守卫者 蘑菇牛 溺尸 末影螨 狐狸 幻翼 岩浆怪 牛 史莱姆 掠夺者 狼 马 幻术师 美西螈 僵尸猪灵 流浪商人 尸壳 山羊 羊驼 熊猫 村民 末影人 雪傀儡 豹猫 流浪者 鳕鱼 蝙蝠 骡 烈焰人 恶魂 兔子 驴 僵尸马 洞穴蜘蛛 监守者

**不会掉落**：末影龙 / 凋灵 / 凋灵骷髅已在配置中显式排除。苦力怕、僵尸、骷髅、猪灵等原版自带头颅仍由原生机制掉落，斩首不额外加成；潜行贝、发光鱿鱼、青蛙、悦灵、骆驼、嗅探兽、吱吱尚未配置专属头颅。

## 附魔冲突（互斥）

以下附魔**无法共存**在同一件物品上（附魔台不会同时出，铁砧也合不上），冲突双向生效。

| 装备 | 附魔 ↔ 互斥对象 |
| --- | --- |
| 弓/弩 | 末影弓 ↔ 力量、火矢、冲击、爆破手 |
| 弓/弩 | 爆破手 ↔ 力量、火矢、冲击 |
| 弓/弩 | 恶魂 ↔ 力量、火矢、冲击、末影弓、爆破手 |
| 弓/弩 | 特殊箭矢类 ↔ 末影弓、爆破手、恶魂 |
| 剑/斧 | 仁慈 ↔ 锋利、亡灵杀手、节肢杀手、火焰附加、吸血、重击、下界克星、村庄守卫、暴怒、狂怒、雷霆 |
| 镐/斧 | 熔炼 ↔ 精准采集、搬运机 |
| 镐/斧 | 范围挖掘 ↔ 爆破采集、连锁采集 |
| 镐/斧 | 连锁采集 ↔ 爆破采集、范围挖掘 |
| 镐/斧 | 爆破采集 ↔ 范围挖掘、连锁采集 |
| 靴子 | 岩浆行走 ↔ 冰霜行者 |
| 靴子 | 弹性 ↔ 摔落缓冲 |
| 诅咒 | 损耗诅咒 ↔ 耐久 |
| 诅咒 | 厄祸诅咒 ↔ 抢夺、时运 |

> **特殊箭矢类（11 种）**：迷惑之箭、黯影之箭、龙焰箭矢、引雷箭矢、爆炸箭矢、火把箭矢、滞空箭、滞留、淬毒箭矢、吸血箭矢、凋零箭矢。彼此**可以共存**，但都不能与末影弓 / 爆破手 / 恶魂 同用。
