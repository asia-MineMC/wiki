# 快速开始

这是一个 VitePress 示例页面，展示 Markdown 的基础用法。

## 本地开发

```bash
npm run docs:dev
```

## 构建站点

```bash
npm run docs:build
```

## 预览构建产物

```bash
npm run docs:preview
```

## 常用语法

### 代码块

```js
const greeting = 'Hello, VitePress!'
console.log(greeting)
```

### 表格

| 命令 | 说明 |
| --- | --- |
| `docs:dev` | 本地开发服务器 |
| `docs:build` | 构建生产版本 |
| `docs:preview` | 预览构建产物 |

> 提示：VitePress 支持完整的 Vue 组件、Markdown 扩展和自定义主题。
