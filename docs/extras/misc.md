服务器还有一批提升体验的便利小功能，这篇一次性讲清楚。

## 服务器主菜单

**Shift + 右键**（潜行右键）打开**服务器主菜单**，几乎所有功能的入口：

- 传送菜单、商城、背包商店、宠物商店
- 公会进贡、会员礼包、指令教学、表情包、维基

> 主菜单里有**「指令教学」**，游戏内直接查指令，和本站内容互为补充。

## 互动书（InteractiveBooks）

服务器部分场景放置了**互动书籍**：

- 右键打开书籍，可以阅读**服务器介绍、玩法说明、剧情**等。
- 部分书籍支持**点击选项**跳转/执行功能（互动式）。
- 看到书就右键看看，常有惊喜（新手引导书强烈建议看）。

## 表情包

- 聊天输入表情代码，展示**服务器表情包**（主菜单 → 表情包查看有哪些可用）。
- 让聊天更有趣，但别刷屏。

## 公告与信息

- **MOTD / 公告**：进入服务器时的欢迎信息、Tab 列表信息由服务器配置，多看两眼不吃亏。
- **自动公告**：服务器会定时在聊天中播报玩法提示、活动预告。
- **维护提示**：服务器维护/重启前会提前公告（自动重启机制），记得提前下线保存物品。

## 常用便利指令速查

| 功能 | 指令 |
|---|---|
| 打开主菜单 | Shift + 右键 |
| 查看帮助 | `/help` |
| 查看插件列表 | `/pl` |
| 查看在线玩家 | `/list` |
| 查询方块记录（防熊） | `/co i`（CoreProtect 查询，查看被谁破坏/拿了什么） |

## 防熊查询（CoreProtect）

如果发现箱子被翻、房子被拆：

1. 输入 `/co i` 进入**查询模式**。
2. 左键点击被破坏的方块/箱子，即可查看操作记录（谁、何时、做了什么）。
3. 再输入 `/co i` 退出查询模式。
4. 把查询结果反馈给管理员处理。

## 小贴士

- 遇到不懂的功能，先翻本站指南，再翻游戏内「指令教学」，最后问管理员。
- 服务器玩法较多，**先把新手板块（签到、任务、领地和商店）吃透**，再进阶。
