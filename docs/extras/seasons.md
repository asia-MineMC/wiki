服务器的世界会**随现实时间流转四季**：春夏秋冬轮换，天气、温度、作物都会受影响——体验更真实的生存。

## 季节机制

- **四季轮换**：世界按现实时间推进季节（春天 → 夏天 → 秋天 → 冬天），循环往复。
- **天气变化**：冬季多雪、春季多雨，各季节天气特征明显。
- **温度变化**：部分生物群系会因季节变得更热/更冷。

## 季节对玩法的影响

| 季节 | 特点 | 生存影响 |
|---|---|---|
| 春 | 温暖、多雨 | 作物生长正常，适合种田 |
| 夏 | 炎热 | 部分群系更热，注意防暑（如有） |
| 秋 | 凉爽 | 作物收获季，树叶变色 |
| 冬 | 寒冷、下雪 | 部分地区结冰/积雪，注意保暖 |

### 种植与农业
- 作物生长受**季节影响**，冬季部分作物可能生长缓慢。
- 建议在**温室/室内**种植，或选择当季作物，保证产量。
- 配合[每日任务](/rpg/quests)的农业任务，选对季节效率更高。

### 生存注意
- 冬季在寒冷群系长时间停留可能**受冻**（如有相关机制），备好火把/暖源。
- 夏季炎热群系注意水分与防中暑（如有相关机制）。

## 小贴士

- 季节变化是**全局**的，全服玩家共享同一季节。
- 主菜单或公告会提示当前季节，多留意。
- 想在固定季节种田？建**室内农场**（有顶棚 + 照明）就不受季节影响。

::: tip 提示
季节系统主要为提升沉浸感，影响程度以服务器设置为准，安心体验即可。
:::
