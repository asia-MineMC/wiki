服务器支持**发红包、抢红包**：在聊天/世界里撒金币红包，大家拼手速（和网速）。

## 发红包

| 功能 | 指令 |
|---|---|
| 打开红包界面 | 主菜单入口，或 `/redpacket` |
| 发随机红包 | 设置总金额 + 红包个数，生成后聊天中出现红包 |
| 发口令红包 | 设置口令，输入正确口令才能领取（如可用） |

### 红包规则（以服务器为准）

- 红包总金额有**上限**（如 100000 金币），单个红包金额有最低值（如 0.1 金币）。
- 红包可以设置**有效时间**，过期未领完的金额**退回**。
- 红包从你的**金币余额**扣除，发之前确认余额充足。

## 抢红包

- 看到聊天/世界中出现的红包，**点击即可领取**。
- 手速决定一切——先到先得，数量有限。
- 每人领取金额**随机分配**，可能拿大头也可能拿零头。

## 常见问题

| 问题 | 说明 |
|---|---|
| 红包被抢完怎么办？ | 拼手速，抢不到很正常，等下一个 |
| 发了红包没人抢？ | 设个口令活跃气氛，或发在人多的时候 |
| 红包显示异常？ | 刷新/重新进入，或稍后再试 |

## 小贴士

- **节日气氛神器**：活动时发红包，全服互动拉满。
- **别发超预算**：红包金额即时扣除，发错不退还，量力而行。
- 口令红包记得口令**别太难**，不然没人抢得到。

::: warning 注意
严禁利用红包进行**赌博/刷钱**行为，发现违规会按服务器规则处理。
:::
