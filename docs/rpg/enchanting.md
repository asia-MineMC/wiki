# 附魔系统（ExcellentEnchants + 拆魔）

服务器的附魔系统基于 **ExcellentEnchants**：除了原版附魔，还有大量**自定义高级附魔**，让你的装备上限大幅提升。

## 自定义附魔从哪来？

- **附魔台**：用附魔台附魔时，有机会随机获得自定义附魔。
- **附魔书**：打怪、抽奖、任务、市场购买获得自定义附魔书。
- **铁砧合成**：用附魔书 + 装备在铁砧上合成。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开附魔管理界面 | `/ec open` 或 `/ec`（有权限时） |
| 查看附魔列表 | `/ec list` |
| 查看附魔详情 | `/ec info 附魔名` |
| 获取附魔书 | `/ec book 附魔名 等级`（有权限时） |

::: tip 说明
普通玩家主要通过**附魔台、抽奖箱、打怪掉落、市场购买**获取附魔，`/ec` 系列多为管理员指令。
:::

## 常见自定义附魔示例

以下附魔类型供参考，具体以游戏内为准：

| 类型 | 例子 | 效果 |
|---|---|---|
| 武器类 | 火焰/冰霜附加、吸血、连锁 | 额外伤害、回复生命、溅射 |
| 工具类 | 连锁挖掘、精准采集强化、自动熔炼 | 挖矿效率翻倍、自动烧矿 |
| 护甲类 | 荆棘强化、伤害反射、移动加速 | 减伤、反弹伤害 |
| 弓弩类 | 多重射击强化、爆炸箭、跟踪 | 更强远程输出 |
| 特殊类 | 经验加成、幸运 | 更多经验/掉落 |

## 拆魔（Disenchantment）

用不上的附魔可以**拆下来**，返还成附魔书，再卖钱或交易。

| 功能 | 指令 |
|---|---|
| 打开拆魔界面 | `/disenchant` 或 `/dis` |
| 拆魔 | 把装备放入界面，选择要拆除的附魔 |

- 拆魔会**消耗一定的金币或物品**（以服务器设置为准）。
- 拆除后附魔变成**附魔书**，可重新附到其他装备上。

## 注意事项

- 自定义附魔等级越高，效果越强，但获取难度也越大。
- 附魔前确认装备：**好的装备值得用好附魔书**，浪费可惜。
- 附魔书可以挂[全球市场](/survival/auctions)卖个好价钱。
