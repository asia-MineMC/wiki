每日任务是稳定的**金币、点券和物品来源**：每天刷新一批任务，完成后领奖，做完全部还有额外奖励。

## 怎么玩？

1. 打开任务界面：`/quests`。
2. 查看今日任务列表（任务目标通常是：击杀怪物、挖矿、采集、合成等）。
3. 按任务要求去完成，进度自动记录。
4. 完成后回到任务界面**领取奖励**。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开任务界面 | `/quests` |
| 查看每日任务 | `/quest daily` |
| 领取任务奖励 | `/quests claim` 或界面内领取 |
| 查看任务进度 | 界面内查看 |

## 任务类型参考

- **击杀任务**：击杀指定数量怪物（僵尸、骷髅、自定义怪等）。
- **采集任务**：挖指定数量矿物（铁、金、钻石等）。
- **农业任务**：收获指定作物。
- **合成/获取任务**：制作或获得指定物品。

## 奖励内容

- 金币（主要奖励）
- 点券（特殊货币，任务的重要来源）
- 物品：附魔书、材料、抽奖箱钥匙等

## 小贴士

- **每天上线先看任务**，顺手把任务做掉，日积月累是一笔不小的收入。
- 任务奖励的点券是**点券的主要获取途径之一**，别错过。
- 某些任务可以在[资源世界](/survival/worlds)快速完成（如挖矿类）。
- 当日任务**次日刷新**，没做完的会消失，尽量当天清完。
