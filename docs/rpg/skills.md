AuraSkills 是 RPG 技能插件：**你平时做任何事——挖矿、砍树、战斗、钓鱼——都会自动提升对应的技能等级**，等级越高，属性越强，还能解锁特殊能力。

## 技能有哪些？

常见的技能分类（以游戏内实际为准）：

| 技能 | 提升方式 | 效果方向 |
|---|---|---|
| 挖掘 Mining | 挖矿/挖石头 | 更多矿物掉落、挖掘加速 |
| 伐木 Woodcutting | 砍树 | 掉落翻倍、更快的砍树 |
| 采集 Farming | 种地/收获 | 作物增产 |
| 战斗 Fighting | 近战击杀 | 伤害提升 |
| 弓箭 Archery | 远程击杀 | 远程伤害提升 |
| 防御 Defense | 承受伤害 | 减伤 |
| 钓鱼 Fishing | 钓鱼 | 更好渔获 |
| 挖土 Excavation | 铲子挖土 | 效率提升 |

## 核心机制

### 经验与升级
- 做对应活动自动获得经验（如挖矿加 Mining 经验），等级自动提升。
- 等级提升带来**永久属性加成**（伤害、速度、幸运等）。

### 能力（Abilities）
- 部分技能升级后会解锁**主动/被动能力**，如"暴击""连锁挖矿""双倍掉落"。
- 主动能力通常消耗**法力（Mana）**，法力会随时间回复。

### 奖励（Rewards）
- 达到特定等级可能获得奖励（属性点、物品等），在技能面板领取。

## 成长建议

- **均衡发展**：前期先点实用技能（挖掘、伐木、战斗），赚钱和战斗两不误。
- **专精流派**：PVP 玩家主点战斗/弓箭/防御；赚钱玩家主点挖掘/采集/钓鱼。
- **配合附魔**：技能加成和[附魔](/rpg/enchanting)叠加，效果更佳。

::: tip 提示
技能等级是全服玩家间差距的核心来源之一，坚持日常活动就能稳步变强。
:::
