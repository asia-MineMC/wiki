每天上线签到、保持在线时长，就能**免费领取金币、点券和物资**——零成本福利，别忘了领。

## 每日签到（LiteSignIn）

### 怎么签到

1. 输入 `/signin`（或 `/qd`、`/sign`，以游戏内为准）打开签到界面。
2. 点击签到按钮完成今日签到，奖励自动到账。

### 签到奖励

- **每日奖励**：金币/点券/物品，每天不同或固定。
- **累计奖励**：连续签到达到一定天数（7 天/15 天/30 天）有额外大奖。
- **漏签处理**：断签后累计天数会重置（部分服支持补签卡，以游戏内为准）。

## 在线奖励（YmOnlineRewards）

按**在线时长**领取奖励：在线时间越长，能领的奖励越多。

### 怎么领取

- 打开在线奖励界面（主菜单 → 在线奖励，或指令），查看当前可领取的奖励。
- 达到对应在线时长门槛后，点击领取。

### 领取规则

- 需要**累计在线时间达标**才能领取对应档位。
- 每档奖励通常**只能领一次**（或按周期重置）。
- 挂机时是否计时以服务器设置为准。

## 常用指令汇总

| 功能 | 指令 |
|---|---|
| 签到 | `/signin` 或 `/qd` |
| 打开在线奖励 | `/reward` 或主菜单入口 |
| 查看累计签到天数 | 签到界面内查看 |

## 小贴士

- **签到 + 任务 + 在线奖励**三件套是零氪玩家最稳定的收入来源。
- 连续签到别断，大奖往往在累计天数后面。
- 点券尽量攒着，等活动或商城好物。
