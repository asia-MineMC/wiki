# 抽奖箱（ExcellentCrates）

抽奖箱是服务器常见的**致富（或致贫）玩法**：花金币抽一次，可能一夜暴富，也可能血本无归（笑）。箱子在各地图摆放，找到就能抽。

## 当前服务器抽奖箱

服务器目前有这些抽奖箱（名称以游戏内为准）：

| 抽奖箱 | 定位 |
|---|---|
| 新手补给箱 | 适合新人，价格便宜，基础物资 |
| 进阶补给箱 | 中期过渡，装备/材料 |
| 专家补给箱 | 价格较高（约 2500 金币），高级奖励 |
| 附魔补给箱 | 附魔书与附魔材料 |
| 锻造模板补给箱 | 锻造模板相关奖励 |

## 怎么抽？

1. **找到抽奖箱**：箱子通常摆放在主城或活动区域，上方有全息文字标价。
2. **右键点击箱子**：打开抽奖界面，消耗对应金币/钥匙即可抽取。
3. 奖励会直接进入背包或掉落，注意查收。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开抽奖箱列表 | `/crates` |
| 查看拥有的钥匙 | `/keys` |
| 预览箱子奖励 | `/crates preview`（看奖励清单，再决定抽不抽） |
| 管理员开箱 | `/crates give 玩家名 箱子名 数量`（管理员） |

## 抽奖技巧

- **先预览再抽**：抽之前用预览功能看看奖励池，值不值一目了然。
- **理性消费**：抽奖本质是概率游戏，设定预算，别上头。
- **关注活动**：节假日/活动期间箱子可能打折或加奖励。
- **新手优先**：新手补给箱性价比高，前期抽这个攒基础装备。

## 注意事项

- 抽奖消耗的是**金币**（或特殊钥匙），从余额直接扣除。
- 奖励是**随机**的，抽不到好东西很正常，别骂服主（狗头）。
- 抽奖获得的物品（附魔书、装备）可以挂[市场](/survival/auctions)回血。
