# 怪物与 BOSS

服务器的怪物体系由 **MythicMobs**（自定义怪物）和 **CustomBoss**（定时 BOSS）驱动，野外不只有原版怪物，还有专属精英怪和定时 BOSS 等你挑战。

## 自定义怪物（MythicMobs）

MythicMobs 会在野外生成**增强型怪物**：血量更高、攻击更强，甚至带特殊技能和掉落。

### 玩家需要知道的事

- **外观与实力**：自定义怪通常有明显的外形/名字/血量条区别，看到别头铁硬刚，先观察。
- **掉落更丰**：击杀自定义怪有更高概率掉落**稀有物品、附魔书、装备**。
- **越级挑战风险**：高级怪可能秒杀低装等玩家，打不过就跑。

### 应对技巧

- 组队打怪更安全：叫上[好友](/social/friends)或[队友](/social/team)。
- 提前准备：好装备 + [附魔](/rpg/enchanting) + 食物 + 金苹果。
- 利用地形：把怪卡在角落或高处，风筝输出。

## 定时 BOSS（CustomBoss）

服务器会**每天固定时间**刷新特殊 BOSS（例如主城公告中的"金猪"）。

### 已知 BOSS 示例

| BOSS | 刷新 | 特点 |
|---|---|---|
| 金猪 | 每天 20:00 | 高血量（8888+）、高伤害，有增益效果 |

> 具体刷新时间与地点以**服务器公告**为准，公告会提前提示。

### 怎么参与

1. 关注服务器公告，得知 BOSS 刷新时间与地点。
2. 提前到场，和其他玩家**一起围攻**（BOSS 通常血量极高，单挑很难）。
3. **输出排名**决定奖励分配（如有排名机制），多打多拿。
4. BOSS 掉落物通常很丰厚：稀有装备、附魔书、抽奖箱钥匙等。

### 注意事项

- BOSS 战区域**可能允许 PVP**，注意防背刺。
- 死亡掉落按服务器规则处理，**别带全部家当去打 BOSS**。
- 活动结束后记得捡战利品，或留意掉落归属（通常按伤害归属）。

## 总结

- 普通玩法：打自定义怪刷材料与掉落。
- 进阶玩法：准点参加定时 BOSS，争夺稀有掉落。
- 记得看公告！服务器活动与 BOSS 刷新都以公告为准。
