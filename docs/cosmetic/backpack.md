背包不够用？好东西没处放？**扩展背包**（BackpackPlus）和**物品银行**（ItemBank）帮你解决仓储问题。

## 扩展背包（BackpackPlus）

额外的背包空间，随时打开使用，相当于随身仓库。

### 怎么用

| 功能 | 指令 |
|---|---|
| 打开扩展背包 | `/bp` 或 `/backpack` |
| 打开指定背包 | `/bp 背包ID`（如有多个背包） |
| 查看背包列表 | `/bp list` |

### 特点

- 扩展背包**随身携带**，走到哪开到哪。
- 可以拥有**多个背包**，分类存放物品（如"矿物包""食物包"）。
- 背包数量/容量可能通过升级或权限扩展。

## 物品银行（ItemBank）

把物品**存进银行**，每天按存款获得**积分**，积分可以兑换奖品——存东西还能生利息！

### 怎么用

1. 打开物品银行：`/itembank`（或 `/bank`，以游戏内为准）。
2. 把可存物品**存入银行**（界面显示每个物品的存入价格）。
3. 每天根据存款自动获得**积分**（日利率见服务器设置）。
4. 用积分去**积分商店**兑换丰厚礼品。

### 取物规则

- **左键取出一组，右键取出多组**（快捷操作）。
- 取出物品可能需要**手续费**（如 5%），留意余额。

### 常见指令

| 功能 | 指令 |
|---|---|
| 打开物品银行 | `/itembank` |
| 打开积分商店 | 银行界面内进入 |
| 查看积分 | 界面内查看 |

## 使用建议

- **仓库分级**：常用物资放扩展背包，囤货放箱子/银行，贵重品存银行还能赚积分。
- **银行攒积分**：不用的矿物、方块存入银行，躺着赚积分，积分商店好东西不少。
- **背包整理**：利用扩展背包分类，出门带装备+食物+工具，效率翻倍。
