在服务器里**自由飞行**，需要消耗**飞行能量**——能量用完就得休息，规划好飞行路线。

## 怎么飞

| 功能 | 指令/操作 |
|---|---|
| 开启飞行 | `/fly`（需要飞行权限） |
| 关闭飞行 | `/fly` 再按一次 |
| 双击空格 | 游戏内快速切换飞行（如可用） |

## 飞行能量机制

飞行不是无限的，消耗**飞行能量**：

- **能量上限**：有上限（如 7000 点），飞完需要等待恢复。
- **消耗规则**：
  - 飞行中**持续消耗**能量（按秒）。
  - 快速移动/距离变化**额外消耗**。
  - 高处坠落（下落）也会消耗。
- **恢复方式**：停止飞行后**自动恢复**，或使用特定道具/技能（以游戏内为准）。

## 常见问题

| 问题 | 说明 |
|---|---|
| 飞行权限怎么获得？ | 通常是会员或特殊身份解锁，普通玩家默认无飞行 |
| 能量耗尽会怎样？ | 自动解除飞行，回到地面行走，等待能量恢复 |
| 飞行中能打怪吗？ | 可以，但注意能量消耗，别飞到一半摔下来 |

## 小贴士

- **规划路线**：能量有限，长距离飞行前确认能量足够，或分段飞行。
- **赶路神器**：配合[随机传送](/survival/rtp)和[玩家地标](/survival/warp)，全图跑图无压力。
- 飞行状态下**死亡掉落**规则与正常一致，别太浪。

::: warning 注意
飞行权限属于特殊身份权益，**请勿共享账号**给别人使用飞行。
:::
