# 宠物系统（MCPets）

宠物不只是装饰——它们会**跟着你跑、陪你战斗、帮你捡东西**，还能升级进化。在服务器里养一只心仪的宠物，旅途不再孤单。

## 怎么获得宠物？

- **宠物蛋**：通过活动、商店、抽奖获得宠物蛋。
- **宠物商店**：主菜单 → **宠物商店**，购买或兑换宠物。
- **活动奖励**：限时活动送限定宠物。

## 常用指令

| 功能 | 指令 |
|---|---|
| 打开宠物界面 | `/pet` 或 `/pets` |
| 召唤/收回宠物 | `/pet spawn` / `/pet despawn` |
| 查看宠物信息 | `/pet info` |
| 宠物改名 | `/pet rename 名字` |
| 宠物技能 | 界面内查看/使用 |

## 宠物玩法

### 跟随与交互
- 宠物会跟随主人移动，右键宠物可以交互（喂食、骑乘等，视宠物类型而定）。

### 战斗辅助
- 部分宠物会**参与战斗**：攻击敌人、吸引仇恨，帮你打怪。

### 拾取物品
- 部分宠物（如拾取型宠物）会帮你**自动捡拾掉落物**，挂机打怪神器。

### 升级进化
- 宠物通过喂食/战斗获得经验，升级后属性增强，甚至**进化成高级形态**。

## 常见问题

| 问题 | 说明 |
|---|---|
| 宠物会死亡吗？ | 一般宠物不会真正死亡，只会暂时收回/消失，重新召唤即可 |
| 宠物能交易吗？ | 视宠物蛋/宠物类型而定，部分可以交易 |
| 有数量上限？ | 可以拥有多只宠物，但**同时只能召唤一只** |

## 小贴士

- 宠物商店定期上新，留意**限定宠物**。
- 战斗型宠物对打[BOSS](/rpg/mobs)很有帮助。
- 给宠物取个有趣的名字，服务器乐趣翻倍。
