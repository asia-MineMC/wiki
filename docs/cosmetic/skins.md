---
title: 皮肤系统
description: 使用正版玩家皮肤或自定义皮肤，外观随心换
---

离线服务器原版无法使用正版皮肤，但本服通过 **SkinsRestorer** 让你**使用任何正版玩家的皮肤**，或者自定义皮肤。

## 怎么换皮肤

| 功能 | 指令 |
|---|---|
| 使用某玩家的皮肤 | `/skin 玩家名`（如 `/skin Notch`） |
| 使用正版 Steve/Alex 皮肤 | `/skin steve` / `/skin alex` |
| 清除皮肤（恢复默认） | `/skin clear` |
| 打开皮肤列表 | `/skins` |
| 使用自定义皮肤 | `/skin set 皮肤ID`（需权限） |

## 其他玩家怎么看我的皮肤？

- 其他玩家需要**重新进入服务器**（或过一段时间）才能看到你的新皮肤。
- 服务器支持**皮肤缓存**，同一服务器内的玩家会同步显示皮肤。

## 常见问题

| 问题 | 说明 |
|---|---|
| 输入玩家名没反应？ | 确认该正版玩家名存在，且皮肤已加载（可以稍等重试） |
| 皮肤加载失败？ | 网络问题或 Mojang 皮肤服务器波动，稍后重试 |
| 能用自定义图片皮肤吗？ | 需要权限，管理员可配置，普通玩家一般用现有皮肤 |

## 小贴士

- 换皮肤**不影响游戏数据**，纯外观，随便换。
- 用知名主播/大神皮肤的同款，回头率拉满。
- 想恢复原版皮肤用 `/skin clear`。
