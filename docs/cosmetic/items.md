# 自定义物品与方块（ItemsAdder）

服务器通过 **ItemsAdder** 加入了大量**自定义物品、方块、家具、装饰**：更好看的家具、独特的工具、自定义食物，还有专属的菜单与资源包。

## 玩家需要知道的

### 自定义物品在哪用？
- 服务器各处的**装饰、家具、招牌**大量使用自定义方块。
- 通过**活动、商店、抽奖、合成**可以获得自定义物品。
- 主城与各大场景都有 IA 制作的建筑与装饰，多逛逛就有感觉。

### 资源包（重要！）
自定义物品依赖**资源包**显示，首次进入服务器请**同意加载资源包**：

- 进入服务器时游戏会提示下载资源包，选择**接受**。
- 若没看到自定义物品/方块显示异常，检查：设置 → 资源包 → 是否已启用服务器的资源包。
- 资源包未加载时，自定义方块会显示为原版占位方块，不影响功能但不好看。

## 常见问题

| 问题 | 说明 |
|---|---|
| 自定义方块不显示？ | 检查资源包是否加载，重新进入服务器 |
| 怎么获取自定义物品？ | 商店、抽奖箱、活动、任务奖励、市场购买 |
| 自定义物品能交易吗？ | 可以，与普通物品一样可交易/上架市场 |

## 小贴士

- **别丢资源包**：卸载/拒绝资源包会看不到服务器特色内容。
- 自定义物品价格通常较高，是**身份与实力的象征**。
- 部分自定义物品有**特殊功能**（如自定义食物回血、自定义工具更耐用），看物品介绍再决定是否入手。

::: warning 注意
- 资源包是服务器官方配置，放心加载，不会影响客户端安全。
- 若多次提示加载失败，尝试更换网络或重启游戏再进服。
:::
