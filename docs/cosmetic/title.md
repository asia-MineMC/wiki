# 玩家称号（PlayerTitle）

称号是显示在你名字前面的**身份标识**，有帅气的前缀文字和样式。收集称号也是服务器的一大乐趣。

## 怎么查看和装备

| 功能 | 指令 |
|---|---|
| 打开称号界面 | `/title` 或 `/pt` |
| 查看可用的称号 | `/title list` |
| 装备称号 | 在称号界面点击对应称号 |
| 卸下称号 | 在界面选择"无" |
| 预览称号 | 界面内点击预览 |

## 称号从哪来？

- **默认称号**：所有玩家可用（如新手类称号）。
- **活动奖励**：服务器活动（节日活动、BOSS 战）发放限定称号。
- **成就/任务**：完成特定目标解锁。
- **充值/会员**：赞助或会员礼包获得专属称号。
- **市场交易**：部分称号可能可以交易（以服务器为准）。

## 称号有什么用？

- **好看**：名字前缀 + 彩色样式，辨识度拉满。
- **身份象征**：稀有称号代表你是老玩家/大佬。
- **部分称号带属性**：个别称号可能有经验加成等效果（以游戏内为准）。

## 小贴士

- 称号是**账号永久**的，换称号随时可换，无损耗。
- 看到心仪的称号，多留意服务器活动公告。
- 称号 ≠ 权限，别以为挂了高级称号就能为所欲为哦。
